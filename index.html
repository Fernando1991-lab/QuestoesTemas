Conectar ao GitHub

Para gravar direto no repositório, o site precisa de um token seu. Crie um fine-grained token com acesso apenas a este repositório e permissão Contents: Read and write, em github.com/settings/personal-access-tokens. Ele fica guardado só neste navegador e nunca é enviado ao repositório.
